# AI Job Search Agent

An AI-powered job search assistant that helps candidates analyze job descriptions, compare them with resumes, generate application emails, create cover letters, write follow-up emails, and track job applications.

## Features

- Resume PDF upload
- Resume and job description match analysis
- Match score generation
- Skill gap identification
- Resume improvement suggestions
- Tailored job application email generation
- Tailored cover letter generation
- Follow-up email generation
- Job application tracker
- Job status updates
- Delete saved jobs
- FastAPI backend
- Streamlit frontend
- SQLite database

## Tech Stack

- Python
- FastAPI
- Streamlit
- OpenAI API
- SQLAlchemy
- SQLite
- Pydantic
- pypdf
- REST APIs
